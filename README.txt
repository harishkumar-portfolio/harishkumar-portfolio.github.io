ASHLEE Luxury Salon & Spa — Portfolio Website
================================================

Open index.html in a browser.

Included:
- Premium responsive UI/UX
- ASHLEE plum/mauve/cream palette
- Hero, services, offer, about, products, gallery, booking UI, testimonials, contact and footer
- Scroll reveal animations
- Hover micro-interactions
- Custom cursor on desktop
- Visual booking confirmation state
- Local reference images supplied for this project

This is a frontend portfolio concept. No backend, database, payment, real booking, WhatsApp, maps, or API integrations are included.
